# Jewel Cloud (주얼 클라우드)

파일 저장, 메일, 회원 관리를 한 곳에서 쓰는 클라우드 서비스 프로그램입니다. PySide6로 만든 데스크톱 클라이언트와 FastAPI 서버, 메일용 TCP 서버로 구성했습니다.

## 주요 기능
- 회원가입 / 로그인: 이메일 인증 코드 확인, 비밀번호는 해시(PBKDF2)로 저장
- 파일 관리: 업로드, 다운로드, 삭제, 폴더 만들기·삭제, 사용량 확인
- 회원 등급별 저장 용량: 일반 100MB / 비즈니스 200MB / VIP 500MB / VVIP 1GB
- 메일: 받은 편지함, 보낸 편지함, 임시 보관함, 휴지통, 메일 쓰기·임시 저장, 삭제 복원·영구 삭제, 검색·읽음 필터·정렬
- 개인 설정: 서명, 다운로드 경로, 휴지통 보관 기간(기본 30일)
- 차단 목록: 특정 회원 차단, 차단한 회원과 메일 주고받기 제한
- 관리자 기능: 공지, 회원 차단·해제, 등급 관리

## 구성
| 폴더 | 설명 |
|---|---|
| `client/` | PySide6 데스크톱 클라이언트 (로그인, 파일, 메일, 설정, 관리자 화면) |
| `server/` | FastAPI 서버 (인증 API, 파일 API) 와 메일 TCP 서버 |
| `mail/` | 메일 관련 데이터베이스 초기화 코드 |
| `source/` | Qt Designer 화면 파일(.ui)과 이미지 |
| `storage/` | 업로드한 파일이 저장되는 폴더 |

## 사용 기술
- Python, PySide6 (Qt Designer로 화면 구성)
- FastAPI, Uvicorn (파일·인증 API)
- TCP 소켓 (메일 서버, JSON 메시지 전송)
- MariaDB (PyMySQL) 【메일 서버는 SQLite 파일을 쓰는 부분이 있어 어느 데이터를 어디에 저장하는지 확인해서 적으세요】

## 실행 방법
1. 라이브러리를 설치합니다.
   ```
   pip install -r requirements.txt
   ```
2. 프로젝트 폴더에 `.env` 파일을 만들고 DB 정보를 적습니다.
   ```
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_USER=사용자
   DB_PASSWORD=비밀번호
   DB_NAME=jewel_cloud
   ```
3. 서버를 실행합니다. 【실제로 쓰는 실행 명령으로 확인해서 적으세요. 예: `uvicorn server.main:app --port 8000`】
   - 메일 TCP 서버는 기본 포트 9000을 씁니다. (`CLOUD_SERVER_PORT`로 변경 가능)
4. 클라이언트를 실행합니다. 서버 주소를 환경 변수로 지정합니다.
   ```
   JEWEL_SERVER_URL=http://서버주소:8000
   python main_gui.py
   ```
